# Proliance сургалтын систем

Proliance-ийн харилцагч байгууллагын ажилтнууд болон Proliance-ийн өөрийн ажилтнуудад (дотоод сургалт) зориулсан бүрэн сургалтын систем: цахим, танхимын (биечлэн), онлайн шууд хичээл, шалгалт, үнэлгээ, заавал хамрагдах сургалтын биелэлтийг нэг дор удирдана. proliance.mn сайтын загварт тааруулсан.

**Технологи:** Next.js 16 (App Router), React 19, PostgreSQL, Node.js 20+.

## GitHub-аас ажиллуулах

### 1. Хөтөч дээр шууд туршиж үзэх (GitHub Codespaces)

Дээрх **Open in GitHub Codespaces** товчийг дарна (эсвэл репо → **Code** → **Codespaces** → **Create codespace on main**). Ойролцоогоор 3–5 минутын дараа PostgreSQL, жишээ өгөгдөлтэй систем асаж, 3000 портын хаяг хөтөч дээр нээгдэнэ. Юу ч суулгах шаардлагагүй.

- Админ: `admin@proliance.mn` / `Proliance2026!`
- Жишээ хэрэглэгчид (нууц үг `Test1234!`): `enkhjin@example.mn` (харилцагч), `coordinator@example.mn` (хариуцагч), `ganbaatar@proliance.mn` (Сургагч эрх), `sarnai@proliance.mn` (Сургалтын админ эрх), `tuguldur@proliance.mn` (шинэ инженер)
- Сервер зогссон бол терминалд: `npm run dev`
- Бусдад үзүүлэх бол **Ports** таб → 3000 → **Port Visibility → Public**.

Codespaces нь туршилт, танилцуулгад зориулсан. Ашиглалтын серверт доорх Docker аргыг хэрэглэнэ.

### 2. Серверт байршуулах (Docker)

Серверт Docker, Docker Compose суусан байхад:

```bash
git clone https://github.com/bilguun-battu/proliance-lms.git
cd proliance-lms
cp .env.example .env      # AUTH_SECRET, APP_URL, ADMIN_PASSWORD, SMTP, SMS-ийг бөглөнө
docker compose up -d      # GitHub-д бүтээгдсэн бэлэн image-ийг татаж, PostgreSQL-тэй асаана
```

- Систем `http://сервер:3000` дээр ажиллана (`APP_PORT=8080` гэж өөрчилж болно). proliance.mn-ий nginx-ээс энэ порт руу дамжуулна (доор "proliance.mn дээр байршуулах").
- Эхлэх бүрт хүснэгтүүд автоматаар шинэчлэгдэж, админ үүснэ. Жишээ өгөгдөл хэрэгтэй бол `.env`-д `SEED_DEMO=1`.
- Шинэ хувилбар гарахад: `git pull && docker compose pull && docker compose up -d`.
- Өгөгдөл `pgdata`, байршуулсан видео/PDF `uploads` гэсэн Docker volume-д хадгалагдана. Нөөцлөх: `docker compose exec db pg_dump -U proliance proliance_lms > backup.sql`.
- Image-ийг өөрөө бүтээх бол: `docker compose up -d --build`. `proliance.mn/surgalt` гэх мэт дэд хаяг дээр бол `docker compose build --build-arg NEXT_PUBLIC_BASE_PATH=/surgalt`.
- Репо хаалттай бол image ч хаалттай: серверт эхлээд `docker login ghcr.io -u bilguun-battu` (GitHub token, `read:packages` эрхтэй).

### 3. Автомат шалгалт (GitHub Actions)

`main` руу push хийх бүрт: төрөл шалгаж, өгөгдлийн сан үүсгэж, бүтээж, серверийг асааж шалгана. Амжилттай бол Docker image `ghcr.io/bilguun-battu/proliance-lms:latest` болж нийтлэгдэнэ.

### Хэрэглэгчийн эрх

- **Proliance админ** — бүх зүйлийг удирдана.
- **Сургалтын админ** — сургагчийн бүх эрхээс гадна шалгалтын болон үнэлгээний материал бэлдэх, хуваарь гаргах, хуваарьт багш оноох, хамтрагч байгууллагын заавал хамрагдах сургалтыг оноох, биелэлтийн тайлан харах. Proliance-ийн ажилтанд олгоно.
- **Сургагч** — багштай холбоотой үйлдэл: өөрийн заах хуваарь, ирц, дүн, шалгалт нээх/хаах, OJT/VoC үнэлгээ. Мөн өөрөө сургалтад сууна. Proliance-ийн ажилтанд олгоно.
- **Байгууллагын хариуцагч** — өөрийн байгууллагын ажилтныг нэмэх, явц харах, мөн өөрөө суралцах.
- **Суралцагч** — байгууллагад нь нээгдсэн сургалтыг үзнэ.

Сургалт нь бүтээгдэхүүнээр дамжин нээгдэнэ: байгууллагад бүтээгдэхүүн нэмэхэд тухайн бүтээгдэхүүний сургалт тэр байгууллагын бүх ажилтанд автоматаар харагдана.

### Модуль дуусгах нөхцөл

**Цахим модуль**
- Видео нь байршуулсан файл, YouTube холбоос эсвэл өөр сервер дээрх MP4/WebM холбоос байж болно.
- Видеог эхнээс нь дуустал 100% бодитоор үзсэн байх. Үзээгүй хэсэг рүү урагш гүйлгэх боломжгүй, тоглуулах хурд 2x-ээс ихгүй.
- PDF гарын авлагатай бол бүх хуудсыг дэлгэцэн дээр гүйлгэж үзсэн байх (хуудас бүр дор хаяж 1.5 секунд харагдана).
- Тесттэй бол тэнцэх оноо авсан байх. Тест материалыг бүрэн үзсэний дараа нээгдэнэ.

**Биечлэн, онлайн шууд модуль**
- Суралцагч хуваариас нэгийг сонгон бүртгүүлнэ. Нэг модульд нэг л ирэх хуваарьт бүртгэлтэй байна.
- Бүртгүүлэхэд баталгаажуулах имэйл, хичээлээс 1 өдрийн өмнө имэйл ба SMS сануулга очно.
- Онлайн хичээлийн холбоос зөвхөн бүртгүүлсэн хүнд харагдана.
- Админ хичээлийн дараа ирц батлахад модуль дууссанд тооцогдоно.
- Хуваарь цуцлахад бүртгүүлсэн хүмүүст мэдэгдэл очно.

Сургалтын тохиргоонд "Модулиудыг дарааллаар нээх"-ийг асаавал өмнөх модулиа дуусгасны дараа дараагийнх нь нээгдэнэ (анхдагчаар унтраалттай).

### Шалгалтын материал ба QR шалгалт

**Шалгалтын материал бэлдэх** (`/admin/exams`):

- **Жагсаалт**: харилцагчийн / дотоод сургалтаар салгана. Ангилал, нэр эсвэл #дугаар, төлөвөөр хайна. "Асуултгүй", "Онооны шатлалгүй", "Үнэлгээний маягтгүй", "Шалгах хариулттай" шүүлтүүр бий. Мөр бүрээс Засах, Хуулбар, Устгах.
- **Тохиргоо**: нэр, хамаарах сургалт/модуль, төлөв (Идэвхтэй / Нуусан), шалгах арга (Автомат / Гараар), дүн харуулах (Шууд / Дараа), хугацаа (0 = хязгааргүй), оролдлогын тоо, тэнцэх хувь, асуулт холих, тайлбар, холбох хичээлийн үнэлгээний маягт, хавсралт PDF (жишээ нь дадлагын үнэлгээний хуудас).
- **Бүлэг**: шалгалт бүлгүүдээс бүрдэнэ. Бүлэг бүрт "санамсаргүйгээр N асуулт харуулна" гэж тохируулна (0 = бүгд). Нэг сэдвийн хэд хэдэн асуултыг нэг бүлэгт хийвэл оролцогч бүрт өөр асуулт оногдоно. Бүлгийн тайлбар оролцогчид харагдана.
- **Асуултын төрөл**: Нэг сонголт, Олон сонголт, Жагсаалтаас сонгох, Богино бичвэр, Урт бичвэр, Тийм / Үгүй / Тайлбар. 10 хүртэл хариулт, асуулт бүрт оноо, зураг. "Хадгалаад дараагийнхыг нэмэх" товчоор асуултыг дараалан оруулна.
- **Онооны шатлал**: авсан оноогоор дүн гаргана (жишээ нь 0–7: Not yet competent, 8–10: Competent). Шатлалгүй бол тэнцэх хувиар.
- **Хуулбарлах**: тохиргоо, бүлэг, асуулт, шатлалтай нь "Нуусан" төлөвтэй хуулбар үүснэ.
- **Хэвлэх материал** (`/print/exam/<id>`): санамсаргүй сонголтоор үүссэн шалгалтын хуудас (нэр, огноо, оноо, багшийн гарын үсгийн хүснэгттэй), ижил кодтой хариултын түлхүүр, асуултын сан бүтнээр. "Өөр хувилбар" товчоор өөр асуулттай хуудас гаргана. A4 хэмжээгээр хэвлэх эсвэл PDF хадгална.

**QR-ээр утсаар өгөх:**

1. **Шалгалт эхлүүлэх**: хичээл дуусмагц "Хуваарь" цэсний тухайн хичээл дээр, эсвэл шалгалтын хуудаснаас "QR шалгалт эхлүүлэх" дарна. Богино холбоос ба QR код дэлгэцэнд томоор гарна.
2. **Оролцогч** QR-ийг уншуулж нэвтэрнэ. Бүлэг бүрээс асуулт санамсаргүйгээр сонгогдоно. Нэг асуулт нэг дэлгэцэнд, хугацаа тоологчтой, хариулт автоматаар хадгалагдана. Тэнцээгүй бол тохируулсан оролдлогын тоо хүртэл дахин өгнө.
3. **Дүгнэх**: сонгох асуултыг систем дүгнэнэ. Бичвэр хариулт эсвэл "Гараар" шалгах шалгалтыг багш "Шалгах" хуудсанд асуулт бүрт оноо өгч, эцсийн дүнг (оноогоор / Тэнцсэн / Тэнцээгүй, жишээ нь Competent) оруулна. Асуултгүй дадлагын үнэлгээнд (VoC) оролцогч бүртгүүлж, багш дүнг оруулна.
4. **Шууд үр дүн**: админы дэлгэц 5 секунд тутам шинэчлэгдэнэ. Хугацааг 10 минутаар сунгах, шалгалт дуусгах боломжтой. Эхэлсэн боловч илгээгээгүй хүмүүсийн хариулт хадгалагдсанаараа дүгнэгдэнэ.
5. **Тэнцсэн** оролцогчийн хичээлийн ирц автоматаар батлагдаж, модуль дууссанд тооцогдоно. Дүнг Excel-ээр татна.

Өмнөх хувилбарын "А, Б хувилбар"-тай шалгалтууд шинэчлэхэд автоматаар бүлэг болж хувирна (хувилбар бүрийн N-р асуултууд нэг бүлэгт орж, тэндээс 1 асуулт сонгогдоно).

### Хуваарьт сургалт ба бүртгэл

- **Хуваарьт сургалт**: танхимын эсвэл онлайн шууд хичээлтэй сургалтын нэг удаагийн хуваарь (дугаар нь ХС-0001 гэх мэт). Нэг хуваарь хэд хэдэн хичээлийн цагтай байж болно (жишээ нь танхимын дадлага + онлайн хичээл).
- **Хуваарь гаргах** (`/admin/sessions/new`): сургалтаа сонгоод хичээл бүрийн огноо, цаг, үргэлжлэх хугацаа, (шаардлагатай бол өөр) багшийг оруулна. Үндсэн сургагч багш (тухайн сургалтыг заах эрхтэй багш нараас эсвэл гадны багш), байршил, онлайн холбоос, дээд/доод багтаамж, хүлээлгийн жагсаалтын багтаамж, бүртгүүлэх ба цуцлах эцсийн өдөр, нэмэлт мэдээлэл.
- **Бүртгэл**: суралцагч хуваарьт бүхэлд нь бүртгүүлнэ. Суудал дүүрсэн бол хүлээлгийн жагсаалтад орно; хэн нэгэн цуцлахад дарааллаараа автоматаар бүртгэгдэж мэдэгдэл авна. Нэг сургалтад нэг л идэвхтэй хуваарь: өөр хуваарьт суудал авахад өмнөх бүртгэл цуцлагдана (хүлээлгийн жагсаалтад орох нь одоогийн бүртгэлд нөлөөлөхгүй).
- **Төлөв**: Бүртгэгдсэн, Хүлээлгийн жагсаалтад, Цуцалсан, Дүүргэсэн, Амжилтгүй.
- **Ирц** хичээл бүрээр: Ирсэн, Хэсэгчлэн ирсэн, Ирээгүй. "Ирсэн" бол тухайн модуль дуусна; бүх хичээлд ирсэн бол хуваарь "Дүүргэсэн" болно.
- **Эцсийн дүн**: Тэнцсэн (Дүүргэсэн, бүх хичээлийн модуль дуусна) эсвэл Тэнцээгүй (Амжилтгүй, дахин бүртгүүлнэ), оноо.
- **Админ** хуваарийн жагсаалт (ирэх, өнгөрсөн, цуцлагдсан) ба сарын хуанлиар харна; суралцагчийг гараар бүртгэх, хүлээлгээс бүртгэх, хасах, хуваарь засах, хичээлийн цаг өөрчлөх, хуваарь цуцлах (бүртгэлтэй бүх хүнд мэдэгдэнэ).
- **Сургагч багшийн самбар** (`/portal/teach`, "Заах хуваарь" цэс): өөрт оноогдсон хуваарь, энэ 7 хоногийн хичээл, ирц бүртгэх шаардлагатай хичээл, хуанли. Хуваарь бүрийн оролцогчдын жагсаалт, ирц, эцсийн дүн, хүлээлгийн жагсаалт, QR шалгалт эхлүүлэх. "Миний хуваарь" дээр ч "Миний заах хичээл" хэсэг гарна.
- Өмнөх хувилбарын модуль тус бүрийн хуваарь шинэчлэхэд автоматаар тус бүрдээ хуваарьт сургалт болж, бүртгэл нь хадгалагдана.

### Дотоод сургалт

- "Байгууллага" цэсэнд Proliance-ийн өөрийн байгууллагыг **"Proliance дотоод"** гэж тэмдэглэнэ. Ажилтнуудыг энэ байгууллагад хэлтэс, албан тушаалтай нь бүртгэнэ (Excel импортод 6 дахь багана "Хэлтэс").
- **Харилцагчийн сургалт ба дотоод сургалт бүрэн тусдаа.** Сургалт үүсгэхдээ аль нэгийг сонгоно. Харилцагчийн сургалт зөвхөн харилцагч байгууллагад (бүтээгдэхүүнээр) нээгдэнэ, дотоод сургалт зөвхөн Proliance-ийн ажилтанд харагдана. Админы бүх цэс (Сургалт, Заавал хамрагдах сургалт, Хуваарь, Тайлан, Тойм) "Харилцагчийн сургалт / Дотоод сургалт" табаар хуваагдана. Нэг талын сургалтыг нөгөө талд оноох боломжгүй (сервер талд шалгана).
- Дотоод ажилтнууд цахим, танхим, онлайн хичээл, QR шалгалт, үнэлгээг ашиглана.

### Дотоод сургалтын төрөл: OJT, VoC, Train the Trainer

| Төрөл | Модулийн хэлбэр | Хэрхэн дуусах |
|---|---|---|
| **On the Job (OJT)** | "Ажлын байран дээр" модуль, даалгаврын жагсаалттай | Ажилтан даалгавар бүрийг гүйцэтгэснээ тэмдэглээд хянагчид илгээнэ. Сургагч эрхтэй ажилтан баталгаажуулна эсвэл засвар хийлгэхээр буцаана. |
| **Verification of Competency (VoC)** | "Ур чадварын баталгаажуулалт" модуль, үнэлэх шалгууртай | Ажилтан үнэлгээ хүснэ (эсвэл үнэлэгч өөрөө эхлүүлнэ). Үнэлэгч шалгуур бүрийг Хангасан/Хангаагүй гэж үнэлж **Competent** эсвэл **Not yet competent** гэж шийднэ. Бүх шалгуур хангасан үед л Competent. NYC бол дахин хүсэлт гаргана. Давтан суух хугацаа (жишээ нь 24 сар) тохируулж болно. |
| **Train the Trainer (TtT)** | Ердийн цахим/танхим модулиуд | Тохиргоонд "Энэ сургалтыг дүүргэвэл ямар сургалтын сургагч болох" гэж сонгоно. Бүрэн дуусгахад тухайн сургалтуудыг заах, OJT/VoC үнэлэх эрх автоматаар олгогдоно. |

- **Сургагч багш** цэс: сургалт бүрийн сургагч/үнэлэгчдийг харах, гараар эрх олгох, цуцлах.
- **OJT / VoC** цэс (админ) болон портал дахь **"Үнэлгээ хийх"** таб (сургагч эрхтэй ажилтанд л харагдана): хүлээгдэж буй хүсэлтүүд, шийдвэрийн түүх. Өөрийгөө үнэлэх боломжгүй.
- Шийдвэр бүр (хэн, хэзээ, шалгуур тус бүрийн дүн, тайлбар) хадгалагдаж, ажилтанд имэйл + мэдэгдэл очно.

### Сургалтын төрөл

Сургалт бүр нэг төрөлтэй: **Цахим**, **Онлайн шууд**, **Танхимын**, **Хосолсон** (цахим + танхим + онлайн модулийг хослуулсан), дотоод сургалтад нэмж **OJT**, **VoC**, **Train the Trainer**. Төрөл бүрт зөвхөн тохирох хэлбэрийн модуль нэмэгдэнэ (жишээ нь цахим сургалтад танхимын модуль нэмэх боломжгүй). Сургалтын жагсаалтыг төрлөөр шүүнэ.

### Албан тушаалын сургалтын матриц

- **Сургалтын матриц** цэс: албан тушаал × дотоод сургалт хүснэгт. Нүд бүрт: шаардлагагүй / нэг удаа / 12, 24, 36 сар тутам.
- Ажилтанд албан тушаал оноох эсвэл өөрчлөхөд (Хэрэглэгч → нэр дээр дарж профайл → "Албан тушаал өөрчлөх") тухайн албан тушаалын заавал хамрагдах сургалтууд автоматаар оноогдож, ажилтанд имэйл + мэдэгдэл очно. Дуусгах хугацаа нь албан тушаалд орсон өдрөөс тоологдоно.
- Албан тушаалын түүх хадгалагдана. Өмнөх албан тушаал дээрээ дуусгасан сургалт профайлд харагдах ба хүчинтэй хэвээр бол шинэ албан тушаалын шаардлагад тооцогдоно.
- Ажилтан заавал биш сургалтад ч өөрөө сонгож сууна. Портал дээр "Заавал хамрагдах" ба "Бусад сургалт" тусдаа харагдана.

### Гэрчилгээ

- Сургалтын бүх модулийг дуусгахад гэрчилгээ автоматаар үүснэ (дугаар `PL-ОН-00001`, олгосон огноо, давтан суух сургалтад хүчинтэй хугацаа, олгох үеийн албан тушаал). Ажилтанд имэйл, мэдэгдэл очно.
- `/cert/<id>`: A4 хэвтээ хэлбэрээр харах, "Хэвлэх / PDF хадгалах". Эзэн, админ, тухайн байгууллагын хариуцагч л харна.
- Гэрчилгээн дээрх QR код `/verify/<дугаар>` хуудас руу орж, нэвтрэхгүйгээр жинхэнэ эсэхийг шалгана.
- Загвар нь түр загвар (proliance.mn-ий өнгө, лого). Proliance загвараа өгсний дараа `src/app/cert/[id]/page.tsx`, `cert.css`-ийг өөрчилнө.

### Профайл ба тайлан

- **Профайл** (админ: Хэрэглэгч → нэр; ажилтан: "Миний профайл"; хариуцагч: "Манай ажилтнууд" → профайл): заавал хамрагдах сургалт, бусад суусан сургалт, гэрчилгээ, албан тушаалын түүх.
- **Тайлан**: "Хүн бүрээр" хүснэгт (заавал хамрагдах: хүчинтэй/нийт, хэтэрсэн, нийт дуусгасан, үүнээс сонгон, гэрчилгээ), явцыг "Нийт суусан / Заавал хамрагдах / Сонгон" ангиллаар шүүх, олгосон гэрчилгээ. Excel-д "Хүн бүрээр", "Явц", "Гэрчилгээ", "Үйлдлийн бүртгэл" хуудас.

### Заавал хамрагдах сургалт (compliance)

- **Оноолт** ("Заавал хамрагдах сургалт" цэс): сургалтыг Proliance-ийн бүх ажилтан, хэлтэс, албан тушаал, харилцагч байгууллага эсвэл тодорхой хүнд оноож болно. Оноосон сургалт тухайн хүнд автоматаар нээгдэнэ.
- **Хугацаа**: оноосон өдрөөс (шинэ ажилтанд бүртгэгдсэн өдрөөс) хойш N хоног, эсвэл тогтмол огноо.
- **Давтан суух**: 6/12/24/36 сар тутам. Гүйцэтгэл хугацаа нь дуусахад хүчингүй болж, модулиуд дахин "үзэх шаардлагатай" болно.
- **Төлөв**: Хүчинтэй · Удахгүй дуусна (30 хоног) · Оноогдсон · Хугацаа дөхсөн (14 хоног) · Хугацаа хэтэрсэн · Хүчингүй болсон.
- **Самбар**: нийт биелэлтийн хувь, сургалт ба хэлтэс/байгууллага тус бүрийн хувь, хүн бүрийн төлөв, шүүлт, Excel.
- Суралцагч "Миний сургалт" хуудсандаа заавал хамрагдах сургалтын төлөв, хугацааг харна. Байгууллагын хариуцагч ажилтнуудынхаа биелэлтийг харна.
- **Сануулга**: өдөр бүрийн cron хугацаа дөхсөн (7 хоног) болон хэтэрсэн хүмүүст долоо хоногт нэг удаа имэйл, SMS илгээнэ.

Жишээ өгөгдөлд "Пролианс ХХК" дотоод байгууллага, 3 ажилтан (ganbaatar@, munkhzul@, baterdene@proliance.mn, нууц үг Test1234!), "Мэдээллийн аюулгүй байдал", "Хөдөлмөрийн аюулгүй байдал" дотоод сургалт, оноолтууд орсон.

### Хичээлийн үнэлгээ

1. **Маягт үүсгэх хэрэгсэл** (`/admin/evaluations`): маягтыг хичээлийн төрөлд (цахим, биечлэн, онлайн шууд, эсвэл бүх төрөл) болон хүсвэл тодорхой сургалтад зориулж үүсгэнэ. Асуултыг хэсгээр (Хичээлийн агуулга, Багшийн заах арга, Зохион байгуулалт, Санал гэх мэт) бүлэглэнэ. Асуултын төрөл: 1–5 оноо, сонголт, сэтгэгдэл. Дарааллыг солих, заавал эсэхийг тохируулах, маягтыг хуулж шинэ төрөлд тааруулах боломжтой. Нэргүй тохиргоотой бол үр дүнд оролцогчийн нэр харагдахгүй.
2. **QR эхлүүлэх**: шалгалтын дэлгэц дээрх "Үнэлгээний QR эхлүүлэх" эсвэл "Хуваарь" цэсний хичээл дээрээс эхлүүлнэ. Систем тухайн хичээлд хамгийн тохирох маягтыг санал болгоно (сургалт+төрөл > сургалт > төрөл > ерөнхий). Шалгалтын QR-ээс тусдаа холбоос, QR үүснэ.
3. **Оролцогч** QR-ийг уншуулж, утсан дээр том товчоор 1–5 оноо өгч, сонгож, сэтгэгдэл бичнэ. Шалгалт өгсөн оролцогчийн дүнгийн хуудсанд "Хичээлээ үнэлнэ үү" товч автоматаар гарна. Нэг хүн нэг удаа бөглөнө.
4. **Үр дүн** шууд шинэчлэгдэнэ: нийт дундаж, хэсэг бүрийн дундаж (агуулга, багшийн заах арга...), асуулт бүрийн 1–5 тархалт, сонголтын тоо, сэтгэгдлүүд. Маягтын хуудсанд бүх удаагийн нэгдсэн үр дүн гарна. Excel-ээр татна.
5. "Үнэлгээ хаах" дарах эсвэл хугацаа (анхдагч 30 мин) дуусахад холбоос ажиллахгүй болно.

Жишээ өгөгдөлд "Биечлэн хичээлийн үнэлгээ", "Онлайн хичээлийн үнэлгээ" маягт орсон.

## Компьютер дээрээ ажиллуулах (localhost)

Шаардлагатай: **Node.js 20 эсвэл түүнээс дээш** (https://nodejs.org). PostgreSQL суулгах **шаардлагагүй**. Windows, macOS, Linux дээр адилхан.

```bash
git clone https://github.com/bilguun-battu/proliance-lms.git
cd proliance-lms
npm install
npm run local
```

`npm run local` дараахыг өөрөө хийнэ:

1. `.env` байхгүй бол үүсгэнэ (санамсаргүй нууц түлхүүртэй).
2. Суулгацгүй PostgreSQL-ийг (`.pgdata` хавтаст) асаана. Компьютерт PostgreSQL суусан, `.env`-д зөв тохируулсан бол түүнийг ашиглана.
3. Хүснэгтүүдийг үүсгэж, админ болон жишээ өгөгдөл оруулна.
4. Системийг http://localhost:3000 дээр асаана. Зогсоох: `Ctrl+C` (өгөгдлийн сан хамт зогсоно, өгөгдөл хадгалагдана).

Бусад сонголт:

| Команд | Юу хийх |
|--------|---------|
| `npm run local` | Хөгжүүлэлтийн горимоор асаана (кодыг өөрчлөхөд шууд шинэчлэгдэнэ) |
| `npm run local:prod` | Бүтээж, production горимоор асаана (хурдан) |
| `npm run local -- --no-seed` | Жишээ өгөгдөлгүй, зөвхөн админтай |
| `npm run setup` | Зөвхөн `.env` үүсгэнэ |

Эхнээс нь дахин эхлүүлэх бол системийг зогсоогоод `.pgdata` хавтас болон `.env` файлыг устгаад `npm run local` ажиллуулна.

### Өөрийн PostgreSQL-ээр (заавал биш)

```bash
npm install
npm run setup -- --own-postgres   # .env үүсгэнэ; DATABASE_URL-ийг өөрийн PostgreSQL-ээр засна
npm run db:migrate                # өгөгдлийн сан байхгүй бол өөрөө үүсгэнэ
npm run db:seed                   # админ + жишээ өгөгдөл (зөвхөн админ: npm run db:seed -- --admin-only)
npm run build
npm start                         # http://localhost:3000
```

Түгээмэл алдаа:

| Алдаа | Шалтгаан, засах |
|-------|------------------|
| `ECONNREFUSED ...:5432` | PostgreSQL ажиллахгүй байна. `npm run local` ашиглана. |
| `password authentication failed` | `.env` доторх DATABASE_URL-ийн хэрэглэгч, нууц үг буруу. |
| Нэвтэрсний дараа дахин нэвтрэх хуудас гарна | `APP_URL` https хаягтай байна. Компьютер дээр `http://localhost:3000` байх ёстой (`npm run local` өөрөө засна). |
| `Node.js ... хуучин байна` | Node.js 20.9+ суулгана. |
| `cookies(...).get is not a function`, `Суулгасан сангийн хувилбар таарахгүй` | `npm audit fix --force` ажиллуулснаас сангууд өөр хувилбар руу солигдсон. `node_modules` хавтсыг устгаад `npm install`, дараа нь `npm run local`. `npm audit fix --force`-ыг бүү ажиллуулаарай. |
| `could not bind IPv4 address`, `Port 3000 is in use` | Порт эзлэгдсэн (ихэвчлэн өмнө ажиллуулсан хувилбар хаагдаагүй). `npm run local` одоо чөлөөтэй портыг өөрөө сонгоно. Хуучныг унтраах бол Task Manager-аас `postgres.exe`, `node.exe`-г хаана. |

Жишээ өгөгдөлтэй бол дараах эрхээр туршина:

## proliance.mn дээр байршуулах

Систем нь тусдаа Node.js процесс бөгөөд сайтын дэд хаяг дээр ажиллана.

1. `.env` дотор `NEXT_PUBLIC_BASE_PATH=/surgalt`, `APP_URL=https://proliance.mn/surgalt` гэж тохируулаад `npm run build` хийнэ.
2. Процессыг PM2 эсвэл systemd-ээр ажиллуулна: `pm2 start npm --name proliance-lms -- start`.
3. Nginx-д дараах байдлаар чиглүүлнэ (видео байршуулалтад 500MB зөвшөөрнө):

```nginx
location /surgalt/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 520m;
    proxy_request_buffering off;
}
```

4. Сайтын цэсний "Нэвтрэх" товчийг `https://proliance.mn/surgalt/login` руу холбоно.
5. Хичээлийн сануулга болон хугацаа дөхсөн сануулгыг өдөр бүр ажиллуулна (cron). Маргааш болох хичээлд бүртгүүлсэн хүмүүст сануулга очно:

```bash
0 9 * * * curl -s -H "Authorization: Bearer <CRON_SECRET>" https://proliance.mn/surgalt/api/cron/reminders
```

6. `UPLOAD_DIR` хавтас болон өгөгдлийн санг өдөр бүр нөөцөлнө.

## Цагийн бүс

Хуваарийн цагийг Улаанбаатарын цагаар (UTC+8) оруулж, харуулна. `APP_TZ` нь харуулах цагийн бүсийг тодорхойлно.

## Имэйл, SMS

- **Имэйл:** `SMTP_*` утгуудыг бөглөнө. Хоосон бол имэйлийн агуулга серверийн лог руу бичигдэнэ (туршилтад тохиромжтой).
- **SMS:** `SMS_API_URL`, `SMS_API_KEY`. Систем `POST {to, text}` JSON илгээнэ. Монголын SMS үйлчилгээ үзүүлэгчийн API өөр хэлбэртэй бол `src/lib/notify.ts` доторх `sendSms` функцийг тохируулна.
